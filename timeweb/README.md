# ENERGY: размещение на виртуальном хостинге Timeweb

Этот вариант работает на обычном PHP-хостинге. Готовая страница, JavaScript, CSS, фотографии и шрифты обслуживаются Timeweb. Форма отправляет JSON в `/api/leads.php`; PHP обращается к Telegram напрямую. Для работы сайта не нужны ChatGPT, Cloudflare Workers, D1 или Node.js на сервере.

## Что уже подготовлено

- Сохранены генераторы, реальные кейсы, фотографии, полные логотипы, шрифты, адаптивная вёрстка и анимации из текущей версии.
- Содержимое страницы предварительно отрисовано в HTML: оно доступно до загрузки JavaScript.
- Добавлены canonical, Open Graph, robots.txt и sitemap.xml для `https://top-generator.ru`.
- PHP проверяет контакт и согласие, ограничивает размер данных, использует honeypot, проверяет время заполнения, Origin и допустимые исполнения.
- SQLite предотвращает одновременные дубли и ограничивает отправки: 4 разных заявки с IP за минуту, окно дублей 10 минут. База хранит только хеши, статусы и время, без контактов и комментариев.
- Успех показывается только после ответа Telegram `ok: true` с положительным целым `message_id`. При неопределённой доставке автоматического повтора нет.

**Перенос считается завершённым только после загрузки файлов на Timeweb, проверки PHP и переключения DNS.** Архив и запись в GitHub сами по себе сайт не переносят.

## Требования

PHP 8.3 или 8.4, расширения `curl`, `mbstring`, `PDO` и `pdo_sqlite`, доступ сервера к `https://api.telegram.org:443`. Сайт должен открываться по HTTPS. Папка `private/storage` должна быть доступна PHP для записи, находясь вне корня сайта.

Node.js нужен только для сборки на компьютере разработчика. На хостинг загружается готовый результат.

## Сборка из GitHub

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm build:timeweb
```

Результат: `outputs/timeweb/`. Папки в пакете:

| Папка | Назначение |
| --- | --- |
| `public_html/` | Только эти файлы доступны через браузер. Здесь страница, ресурсы и `/api/leads.php`. |
| `private/` | Серверный обработчик, конфигурация и автоматически создаваемое хранилище. Рядом с `public_html`, вне него. |

При сборке реальные `.env`, `config.php` и папка `storage` исключаются. В пакет включён только пример настроек без секретов.

## Загрузка через панель Timeweb

1. Создайте отдельный сайт для `top-generator.ru` в разделе «Сайты». Выберите PHP 8.3 или 8.4. Если домен ещё занят другим сайтом, сначала разверните этот вариант на техническом адресе.
2. Откройте «Файловый менеджер» и перейдите в папку нового сайта, **на уровень выше `public_html`**. Загрузите и распакуйте подготовленный пакет здесь. Итог: `папка_сайта/public_html/index.html` и `папка_сайта/private/lead-handler.php`.
3. Проверьте, что `index.html` оказался прямо в `public_html`, без дополнительной вложенной папки. Резервную копию прежнего сайта храните за пределами `public_html`.
4. В папке `private` скопируйте `.env.example` в `.env`. Секреты задаются именованными переменными окружения в этом приватном dotenv-файле либо в серверном окружении. Ограничьте права `.env` до `600`, если это поддерживается файловым менеджером; рабочие каталоги должны оставаться доступны PHP вашего аккаунта.
5. В `.env` заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Дополнительно можно задать `TELEGRAM_MESSAGE_THREAD_ID` и случайный `LEAD_HASH_SALT`. Значения не вычисляются и не подставляются в клиентский код. Не добавляйте `.env` в GitHub.
6. При необходимости скопируйте `config.example.php` в `config.php` для несекретных настроек. Для проверки по техническому адресу добавьте его точный origin (протокол и имя хоста) в `additional_origins`. Используйте только фактически выданный Timeweb адрес. `site_origin` оставьте `https://top-generator.ru`.

`private` нельзя загружать внутрь `public_html`. Обработчик дополнительно отказывается работать, если его приватный каталог или база оказались внутри document root.

## Проверка перед переключением

- По техническому адресу видна именно новая страница ENERGY, фотографии и шрифты загружаются. Меню, исполнения, кейсы и форма работают на телефоне.
- Без настроенного Telegram форма должна показать ошибку, а не сообщение об успешной отправке.
- После подключения бота отправьте одну явно обозначенную тестовую заявку. Проверьте фактическое сообщение в нужном чате: контакт, задачу, исполнение, страницу и UTM. Убедитесь, что повтор не создаёт ещё одно сообщение.
- Убедитесь, что приватные конфигурация и база недоступны через браузер, а `public_html` не содержит секретов или SQLite-файлов.

## Переключение top-generator.ru

1. Получите **фактический IP сервера виртуального хостинга** из панели Timeweb. IP из примеров и старые адреса Cloudflare использовать не нужно.
2. В DNS Timeweb замените две A-записи корня `162.159.143.30` и `172.66.3.26` на выданный Timeweb IP. Записи MX и `quiz.top-generator.ru` сохраните. AAAA добавляйте только если Timeweb выдал IPv6 для этого сайта.
3. Выпустите бесплатный SSL в Timeweb, дождитесь его активации, затем включите в панели перенаправление HTTP на HTTPS.
4. Проверьте адрес без авторизации и без VPN с компьютера и телефона, в том числе через мобильную сеть. Проверьте отправку тестовой заявки после перехода на основной домен.
5. После подтверждения работы можно удалить служебные TXT `_openai-site-verification` и `_cf-custom-hostname` и снять привязку домена к прежнему хостингу. Они не мешают запуску нового сайта, поэтому это делается после проверки.

До завершения проверки рабочую копию и прежнюю привязку не удаляйте. Для отката восстановите две старые A-записи и дождитесь обновления DNS.

## Тесты обработчика

```sh
php tests/timeweb-leads.test.php
```

Тесты запускаются в Linux / WSL с PHP CLI, `mbstring`, `pdo_sqlite` и `pcntl`. Используются настоящая SQLite и подменённый сетевой транспорт: сообщения в Telegram не отправляются. Покрываются подтверждение и отказ Telegram, отсутствие секретов, некорректный ввод, Origin, согласие, лимиты, дубли, неопределённая доставка, параллельные запросы из отдельных процессов и освобождение блокировок после истечения срока.
